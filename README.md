# DESI — 水光數域

一個以原生 HTML、CSS 與 Canvas 2D 製作的互動式數學探索網站。

線上版本：<https://xieyaozhong.github.io/DESI/>

## 探索內容

- 雙波源干涉：調整波源距離、波長與相位差
- 李薩如軌道：觀察頻率比例如何形成封閉曲線
- 對數螺旋：改變每四分之一圈的成長倍率
- Mandelbrot 集合：點擊或使用鍵盤平移、縮放無限邊界

網站不使用框架、遠端字型或外部影像素材，可直接由 GitHub Pages 發佈。

## 本機預覽

在專案根目錄啟動任一靜態檔案伺服器，例如：

```sh
python -m http.server 4173
```

再開啟 <http://127.0.0.1:4173/>。
