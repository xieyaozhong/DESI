//03 Profile / code × form × behavior

METHOD

Build the
behavior.

不是先做一張靜態畫面，再補動畫；而是把「如何移動、如何回應、如何失敗、如何恢復」一起當成設計本體。

A system
should feel
inevitable.

好的互動作品會讓技術藏在體驗裡。架構要足夠清楚，動態要有物理感，資訊要有層級，而每一個細節都應該服務同一個世界觀。

DESI 使用原生 JavaScript、Canvas 2D 與 WebGL，刻意保持系統透明：每一層視覺都能追溯到一個規則，每一次互動都有可理解的原因。
