01 / BACKGROUND專案背景
現有資產

先利用已經存在的優勢。

中部已有圍棋人口與固定聚會，但由職業棋士長期在地參與、經營與推動的交流節點相對稀少。現階段不急著增加固定成本，而是先把既有專業、空間、人脈與案例變成可驗證的系統。

PROFESSIONAL職業棋士背景 × 長期教學經驗
SPACE彰化既有實體空間，可交流、教學甚至住宿
NETWORK彰化固定棋聚、棋友、家長與相關教育人脈
OBSERVATION NODE每週二彰化黑嘉嘉圍棋教室棋聚
CASE BASE既有學生與真實教學案例
METHOD正在系統化的個人圍棋教學方法
PARTNERS黑嘉嘉彰化加盟主與教育／商業連結
LEVERAGEAI、軟體與網路經營合作資源
現階段優先：實體連結 × 教學產品化 × 內容展示 × 市場反饋
02 / GOAL核心目標
不是地點問題

真正的問題是：
如何讓適合的人找到我們？

長期希望累積一群認同教學理念、願意長期學習，並能透過持續訓練取得棋力與競賽成果的學生。學生來源不預設只能來自彰化。

PHYSICAL

彰化／台中／中部跨區

利用既有場域、合作教學或彈性租借，不先承擔固定教室成本。

ONLINE

台北、高雄、海外華語

把教學方法與案例轉換成可以遠距理解與長期使用的產品。

HYBRID

實體＋線上混合

依學生需求配置面授、線上、集訓與研究型學習。

03 / PRODUCT核心教學產品假說
六個特徵

不是只教正解。
而是建立自己的決策系統。

我們不只問「這手棋對不對」，而是追查孩子為什麼做這個決策、看見了什麼、忽略了什麼，以及下一次能不能自己重新判斷。

01 / DECISION SYSTEM

決策系統

理解答案背後的判斷生成方式，而不是只修正單一棋步。

02 / DELAY THE ANSWER

不急著給正解

先理解原本思考；卡住時再透過提問、支架、示範與選項降低難度。

03 / MULTIPLE SOLUTIONS

多解思維

AI 或職業棋士的答案不是唯一目的；學生要會比較選項、理解理由並做選擇。

04 / COGNITIVE EDGE

看得見／看不見

診斷不只看答對答錯，而是辨認學生目前認知邊界在哪裡。

05 / AGENCY

自主學習

從「老師今天教什麼」逐步走向「我今天想研究什麼」，最終能自主覆盤。

06 / TRANSFER

跨情境遷移

目前已有學生自主調用過往策略、主動提出研究問題等早期案例，仍需持續驗證。

04 / STRATEGY三條線並行
A / B / C

Product × Network × Window

A
PRODUCT / 教學產品

我的教學到底有什麼不同？

持續紀錄教學案例、學生決策、錯誤模式、提問、支架、多解、自主學習、棋力與比賽成果。

把個人經驗變成：
可理解、可展示、可驗證的方法。
B
NETWORK / 實體連結

誰可能需要？誰能讓我們遇見？

以黑嘉嘉彰化棋聚、中部棋友、家長、老師、棋士、教育、商業、科技節點逐步建立 Network Map。

不問「加了幾個 LINE」，而問：
理解了哪一個重要節點？
C
WINDOW / 展示窗口

離開現場後，如何繼續理解我們？

第一目標不是流量，而是讓新認識的家長／棋友在 5–10 分鐘內理解我們是誰、怎麼教、差異在哪。

最重要的內容資產：
真實決策故事。
01學生原本怎麼想
02老師問了什麼
03看見／沒看見什麼
04提供哪些選擇
05學生如何重判
06之後能否自主使用

06 / TUESDAY FIELD LAB每週二任務
自然觀察

不做正式問卷。
先學會看現場。

每次棋聚優先自然觀察五件事情。原始語言與行為資料先保存，再做解釋。

01

Customer Language

家長如何自然描述孩子？保留原話，例如「他很粗心」「比賽就會緊張」「同樣的錯一直犯」「他很會算但不敢下」。

02

Social Currency

觀察社群真正重視什麼。

  • 段位、比賽、得獎、棋力
  • 興趣、老師、升學、同儕
  • 競賽成果究竟代表投資證明、成就、身份認同還是社會比較？
03

Outlier

尋找非典型家庭：高度投入、競賽導向、純興趣、高資源、自主性高、多才藝。極端樣本常比平均值更容易揭露機制。

04

Network Node

了解新認識的人在生態中的位置：家長、老師、教室、棋士、教育、商業、科技或其他。重點是理解節點，不是蒐集聯絡人。

05

Product Demo

如果自然出現棋局討論，就直接使用自己的教學方式。不要先講六點理念，而是讓產品直接發生，再觀察孩子與家長反應。

Observation ≠ Interpretation
先保存原始資料，再進行分析。
每週最小紀錄 / 10 MIN FIELD LOGAUTO-SAVED LOCALLY
保存原始語言，不急著解釋。
描述行為，而不是先貼標籤。
建立 Observation → Hypothesis 的連結。
人名可簡寫；重點是生態位置與連結能力。
每週至少允許一個假設被現實改寫。

08 / MVWMinimum Viable Window
最小展示窗口

第一版只需要完成一個 Job。

THE JOB

讓剛認識我們的人，可以快速繼續了解我們。

不是一次做完整品牌網站、YouTube、FB、IG、Threads。第一階段的評估指標也不是粉絲數，而是：看完的人是否更理解這套教學。

01
我是誰簡單、可信的專業背景。
02
我怎麼看圍棋教育核心理念，不需要堆疊術語。
03
我怎麼教用真實案例，而不是自我宣稱。
04
學生發生了什麼改變行為／思考／棋力／比賽案例。
05
如何繼續接觸聚會、交流、教學或聯絡方式。

14 / DECISION RULES專案決策原則
提高取得答案速度

不預測最終答案。
而是提高取得答案的速度。

01小成本

不做重資產押注。

02高頻率

每週取得真實資訊。

03真實世界

行為資料優先於問卷意見。

04案例優先

真實學生改變優先於品牌文案。

05可逆 × 飛輪

前期選容易修改的行動，最好同時增加 Product / Network / Content / Information。
